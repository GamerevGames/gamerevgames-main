About the studio

Gamerev Games is a game studio founded in 2017 by Travis Carpenter. The name invokes a sense of revolution in the video game world. We focus on creating gameplay-driven experiences built with intention. Gamerev Games isn't chasing trends; we craft games with substance, edge, and a clear respect for our players.

What makes us different

Action Packed

Fast, responsive combat and movement that rewards skill and keeps the pace high.

Crafted with Care

Every system, animation, and detail is built and tested with respect for the player's time.

Future Vision

We build with modern tools and an eye on what's next, so each game pushes further than the last.

Our technology

We build in Unity 6, which lets us create responsive, systems-driven gameplay and iterate quickly. Tight mechanics, strong performance, and a memorable experience are what we aim for in every project.
